# dsh-image-studio 开发计划

最后更新：2026-11-09（对应 0.21.0）
基线：`origin/main` 与本地一致；插件测试 **261/261**，原生桥接测试 **34/34**。

## 目标

让这个 DSH 图片插件能**自主完成套版图**：自主抠图 → 找素材 → 套模板 → 排文字 → 批量出成品，
全程有人可核对的中间态，不把 mock 当生产能力。

## 进行中 / 下一步（按优先级）

## 优化计划（0.25 → 0.27）

原则：**先让 agent 能自查，再让确认更可信，最后才是画质。** 依据是 pedit 的 `preview`/`analyze_image`/`review_image`
三件套——它的 agent 不是"做完就宣称完成"，而是"量一遍再改"。

### P0-1 自检：`analyze` + `review`（0.25.0）

现状：模型的唯一反馈是 `revision` 和图层列表，看不到曝光、裁切、颜色偏移，只能凭感觉宣称"好了"。

要做：
- 编辑器新增 `editor.analyze`：在**降采样**后的合成图上算
  - 平均亮度、直方图粗分桶、暗部/亮部裁切比例（<4 / >251 的像素占比）
  - 颜色偏置（R/G/B 均值差）、清晰度（Laplacian 方差，降采样后算）
  - 图层是否越出画布、是否有零尺寸图层、文字层估计宽度是否超出画布
- 新增工具 `media_image_analyze`：回上述测量 + `findings[]`（每条带 `suggestedCommand`，如"高光溢出 → `layer.color_match` 或降低亮度"）
- 规则：**只测量、不给主观评价**；测量失败如实返回 `needs_data`，不编数字

验收：自造三种图（全黑 / 过曝 / 偏蓝）测出的裁切与偏色方向正确；越界图层被点名；`findings` 中每条 `suggestedCommand` 必须存在于白名单（测试逐条核对）。

### P0-2 确认卡片可核对（0.25.0）

现状：确认框展示原始 `payload` JSON，人看不出「这个 layerId 是哪一层」。

要做：解析成 `图层名 · 类型 · 坐标·尺寸` 再展示；套版/重绘/批量的确认框统一走同一个渲染函数。

验收：确认框文本里出现真实图层名与尺寸；测试断言解析字段（不存在的 id 显示 `(图层已不存在)` 而不是空白）。

### P1-1 送后端的蒙版羽化（0.26.0）

现状：选区路径的蒙版是硬边（`fillRect` 纯白），模型容易把主体画出选框、留接缝。

要做：导出前对外缘按选区较长边 1/8 做渐隐（复用已有 `blurAlpha`）。

验收：导出的蒙版 PNG 在边缘 alpha 呈梯度；单测断言梯度宽度与中心不透明。

### P1-2 重绘上下文裁剪 + 尺寸回执（0.26.0）

现状：整图送后端，尺寸不可控也不告诉用户。

要做：`command` 后端支持 `crop.context`（按选区较长边外扩，默认 25%），回执写 `720×760 → 992×1040`。

验收：单测断言裁剪框计算（含贴边情形）；回执包含两组尺寸。

### P1-3 预览图（0.26.0）

要做：`editor.preview_png { maxWidth }` 返回降采样 PNG data URL（默认 640px、质量 0.7，≤256 KB）；
`media_image_analyze` 可一并回 `preview`，供能显示图片的宿主直接看。

诚实边界：**能否"看见"取决于宿主是否把 tool 结果里的图渲染给模型**；不能渲染时它就是一个可保存的缩略图，不宣称模型看见了。

### P2-1 PSD 混合模式与图层蒙版（0.27.0）

现状：一律 source-over；图层蒙版/剪贴蒙版未处理。

要做：支持 multiply/screen/overlay 等常用模式；应用 alpha 通道 -2 作为图层蒙版；不支持的模式**明确登记**。

验收：自造 PSD 与手算结果逐像素一致；不支持项出现在 `skipped`/`approximated`。

### P2-2 批量可配 + 清单（0.27.0）

每份可配 `texts` 与 `slotId`（API 已支持，界面未暴露）；批量结束产出清单 JSON（文件名 ↔ 素材引用）。

### P3 阻塞项：真实重绘后端

本机无重绘模型（ComfyUI 端口未监听、无本地脚本）。需要你定：**本地脚本**（`kind: command`）还是 **ComfyUI**。
在此之前不会声称「局部重绘已跑通」。

## 明确不做（本轮）

- MCP 服务层：DSH 已有 tool 面，再叠一层只多一处鉴权面。
- GPU/合成引擎重写：当前目标不需要。
- 让 `command` 后端的命令由模型指定：那等于把本地命令执行权交给模型，保持只由操作者配置。

## 纪律

- 每版：全量测试 → 构建 → `pack-image` → 部署 profile → 提交 → tag → Release。
- 每条能力：先定义可失败的验收，再实现；没跑过的不写成已跑通。
- 中文源码只用文件工具改，不用 PowerShell 批量替换（见 ADR 记录）。
